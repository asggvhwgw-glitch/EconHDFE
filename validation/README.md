# External Stata validation harness

**Status:** external-validation scaffold; licensed Stata execution is not performed by ordinary GitHub CI.  
**Fixture contract:** the current historical fixture set is labeled `v0.8.0`; that label identifies the validation corpus and does not redefine the package release version.

Stata and Python must consume exactly the same deterministic fixtures. The generator writes both the ordinary panel fixture and a long-format patent–inventor-style membership fixture; Stata never regenerates the DGP.

## Reproduce

From the repository root:

```bash
python validation/make_fixture.py
stata-mp -b do validation/stata/generate_golden.do
PYTHONPATH=. python validation/compare_golden.py
```

Before the Stata step, install and record pinned Stata, `reghdfe`, `ivreghdfe`, `ivreg2`, `ranktest`, and `ftools` versions. Archive those versions together with `golden_results_stata.csv` and the comparator output.

## Fixture coverage

The `v0.8.0` corpus prepares **23 rows**. It retains the 18 historical OLS/IV/weights/VCE/group-individual cases and adds five structural-design cases:

- hierarchical `firm + year + province#year + city#year` absorption, with Python canonicalization to `firm + city#year`;
- ordinary `firm + year` absorption with Python `method="auto"`, expected to route to the specialized two-way solver;
- an exactly collinear `x + w + x3` design with explicit user omission of `x3`;
- a `year` factor block structurally absorbed by `city#year`;
- an event-study interaction with `event_code=2` as the explicit reference plus a never-treated zero interaction that remains an automatic omission.

The Stata CSV records `x`/`w` coefficients and SEs, their covariance, an additional event coefficient/SE where applicable, `N`, absorbed DoF, and available weak-ID diagnostics. `compare_golden.py` treats every finite recorded statistic as required and also checks package-side metadata semantics.

## Claim boundary

The repository deliberately does not ship a fabricated `golden_results_stata.csv`. Commit or archive one only after it is actually generated by a recorded licensed Stata environment. Repository-local numerical oracles and CI do not substitute for this external validation step.
