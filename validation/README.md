# Stata golden validation — v0.8.0

> **Validation status:** Current harness documentation. The `v0.8.0` label names the historical fixture corpus and is not the current package version.


Stata and Python must consume exactly the same deterministic fixtures. The generator writes both the ordinary panel fixture and a long-format patent–inventor-style membership fixture; Stata never regenerates the DGP.

Run from the repository root:

```bash
python validation/make_fixture.py
stata-mp -b do validation/stata/generate_golden.do
PYTHONPATH=. python validation/compare_golden.py
```

Before the Stata step, install and record pinned Stata, `reghdfe`, `ivreghdfe`, `ivreg2`, `ranktest`, and `ftools` versions. Archive those versions together with `golden_results_stata.csv` and the comparator output.

The v0.8.0 harness prepares **23 rows**. It retains the 18 historical OLS/IV/weights/VCE/group-individual cases and adds five v0.8 cases:

- hierarchical `firm + year + province#year + city#year` absorption, which Python must canonicalize to `firm + city#year`;
- ordinary `firm + year` absorption with Python `method="auto"`, which must route to the specialized two-way solver;
- an exactly collinear `x + w + x3` design with explicit user omission of `x3`;
- a `year` factor block structurally absorbed by `city#year`;
- an event-study interaction with `event_code=2` as the explicit reference and a separate never-treated zero interaction that must remain an automatic omission.

The Stata CSV records `x`/`w` coefficients and SEs, their covariance, an additional event coefficient/SE where applicable, `N`, absorbed DoF, and available weak-ID diagnostics. `compare_golden.py` treats every finite recorded statistic as a required check. It also asserts v0.8-only Python metadata semantics so canonicalization, solver routing, and user-versus-automatic omissions cannot silently regress while preserving the same coefficient vector.

The repository deliberately does not ship a fabricated `golden_results_stata.csv`. Commit or archive one only after it is actually generated by a recorded licensed Stata environment.
