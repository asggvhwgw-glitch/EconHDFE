# Linear IV：单次拟合内的计算复用

这些优化改变执行方式，不改变模型、样本、权重、必需的秩/识别检查或默认诊断范围。没有新增用户配置项；所有复用状态仅存活于当前拟合。

## 模块职责

- `collinearity.py`：保留原始设计与吸收后设计的双重检查，复用已形成的Gram，避免递归检查再次扫描相同输入。Gram条件不佳时仍执行原设计QR检查。
- `models/linear_iv/solve.py`：利用`X=[C,E]`、`Z=[C,I]`的角色关系，仅对内生变量求首阶段；同一个分块QR压缩工具、内生变量和y，第二阶段使用小矩阵SVD。秩阈值继续依据原始N，尺度继续依据观测空间投影设计。通用`iv.solve.weighted_2sls`供IV-PPML/GMM使用，合同不变。
- `models/linear_iv/estimators.py`：传递已加权数组，接收已有残差；识别检查形成的XX/ZZ/XZ供诊断复用。普通2SLS单向聚类在安全分支共享原始工具得分聚合，主VCE独立施加小样本修正并保持协方差对称化，over-ID使用未修正矩阵。
- `models/linear_iv/diagnostics.py`：控制投影及AP/SW可复用求解器的小型QR因子；Shea改用小矩阵乘法并延迟到实际需要时计算。高级关闭仍不计算Shea/AP/SW/CD/Stock–Yogo，KP仍保留。
- `compute/vcov.py`：按列聚合KP的Kronecker得分，单例交叉聚类使用分块HC0恒等式；保持CGM包含排除顺序和组数检查；大组矩阵按完整组分块，避免回退到全样本得分展开。

正式实现使用直接函数和小型因子对象，没有实验原型中的monkeypatch、动态源码克隆、全局数值缓存或跨Session缓存。

## 数值回退

工具QR接近奇异时使用既有角色化观测空间解法，并保留不含y的首阶段QR布局：增加y列会改变舍入，在病态工具下可能放大为结果差异。此分支共享已加权输入和尺度，QR构造与结果组装只有一份实现。控制投影、AP/SW遇到条件数或消减边界时保留GELSY/原计算路径。KP的满得分、近完美拟合和秩边界回退保持不变。

过度识别检验也受矩条件保护：`(X'Z)'`与`Z'X`虽然代数等价，舍入差会在病态求逆时放大；不安全分支必须保留原乘法顺序，不能通过放宽验证容差接受差异。

这些阈值只选择执行分支，不改变模型列、报告秩或经济学识别定义。固定kappa、Fuller、LIML、GMM和block路径只使用其适用的共享组件，不强行套用普通2SLS专属求解器。

## 输出与生命周期

[分阶段结果与高级诊断开关](iv-staged-diagnostics.md)的公共合同保持不变：默认完整诊断；关闭高级仍保留普通首阶段F、partial R²、KP和over-ID。同步阶段快照不携带逐观测工作区。

QR对象只含小矩阵与尺度向量，工作区只接收同一拟合的因子和矩。样本、权重、尺度变化后必须重新构造，不复用跨模型数值状态。重复加权的节省主要适用于有权重拟合；无权重时原加权函数本来就返回原数组。

## 验证边界

使用独立基线源码对照系数、VCE、残差、诊断、DoF、错误和阶段快照，并覆盖近共线、近完美拟合、量纲、权重及协方差分支。定向测试见`tests/numerics/test_iv_reuse.py`及既有IV/聚类/权重回归。

性能必须以同批次、相同FE实现的完整拟合比较；不要累计不同原型批次的百分比。RSS与活跃数组峰值分别报告。这里使用既有QR、矩阵运算与聚类恒等式，不作新计量算法或外部Stata认证声明。
