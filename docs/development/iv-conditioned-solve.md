# 普通 2SLS 的病态设计分支

普通 dense 2SLS 中，控制变量同时出现在结构矩阵和工具矩阵。控制变量近共线时，列范数归一的 `X'Z` 可以比投影设计更病态。因此，该路径把原矩条件检查作为执行路由：比值低于原有 `1e-3` 分支门槛时，由实际加权设计的 QR/SVD 复核识别并求解，不再先由交叉矩阵拒绝。

这不改变样本、模型列、权重或工具定义。Block、LIML、Fuller、固定 k-class 和 GMM 保留原数值保护。条件良好的普通 2SLS 保持已有求解与推断路径。

## 数值机制

- 两层分块 TSQR 压缩工具、内生变量和响应；工具秩及投影设计秩在小矩阵上由 SVD 判断，保留原始样本量相关秩阈值。
- 先剔除控制空间，再用内生变量与排除工具空间的最小典型相关区分数值识别边界。`sqrt(eps)` 仍保护数值上不可分辨的方向；这不是统计弱工具检验。
- 一次分块正交回放同时提供残差、内生变量拟合值、剔除控制后的诊断角色以及推断得分。首阶段系数仅用于报告，不用于在近共线工具中重建投影。
- 协方差直接累计系数影响量的得分，避免巨大 bread 与 meat 相乘时的相消；过度识别检验在正交工具坐标中计算，正定得分协方差使用白化最小二乘。
- 稳定诊断保留控制变量自由度。KP/CD 使用白化内生变量；Shea 使用剔除控制后设计的 QR/SVD 逆对角比；AP/SW 在稳定的小矩阵坐标中计算。

已确认缺少识别方向仍报告欠识别；工具设计数值不可分辨或极端近识别则报告数值错误。没有通过截断后返回少列解来掩盖失败。

## 吸收后的弱控制方向

500万综合压力样本首先暴露了独立的吸收误差：稳定IV核心在解析投影上的系数相对误差约4e-10，但完整吸收后的两个近共线控制系数相对差约2e-5。为此，普通2SLS的纯分类 NumPy MAP 路径增加局部认证修正。

吸收后先对控制矩阵做分块归一化Gram筛查；仅在条件不佳时用QR/SVD确认弱方向。逐个构造原始控制的弱线性组合，放大到单位组内尺度，先执行最多8次MAP；若原容差的正交性证书不通过，则复用已有LSMR投影。LSMR的范数停止规则不直接保证最大FE均值误差，因此根据独立证书最多进行3轮有界求解，仅在需要时收紧内部容差，最后最多8次MAP精化；最终仍严格按原 `tol` 认证，再将差额映回原列。只改变数值计算，不改变模型列或工具角色。秩不足交回原遗漏规则，不收敛交回原公开收敛策略。

每次只处理一个弱方向，工作向量及LSMR临时量为O(N)，不增加全样本宽矩阵；原吸收器的线程与每方向总迭代上限继续生效。无FE、异质斜率及不支持正交性认证的后端不启用此修正。控制中存在吸收后零列或精确冗余列时，先按原遗漏规则选择控制，再修正保留控制的弱方向，最后使用修正后的控制空间检查内生变量和排除工具的冗余；`collinearity='raise'` 仍在发现冗余时立即报错。`absorb_info['control_refinement']` 记录弱方向数、单方向最大迭代、全部方向总迭代、各轮内部容差、认证状态及分段计时；主结果迭代数仍描述原吸收过程。

## 性能和内存

稳定分支只对困难样本触发，正常路径不增加全样本 QR。TSQR 存储块级小因子，回放只构造当前块的正交基，不持有完整 N×L Q 或额外 N×K 投影设计。

聚类缓存（包括持久分组编码、查找表、得分及单例HC0）及 HAC/DK 完整得分存储各有 256 MiB 的内部保护；超过时明确报告资源限制。这不是总进程内存预算，原始设计、权重、临时分组操作、窄诊断角色和输出数组仍占内存。权重稳定分支复用已有加权角色，推断完成后释放不再需要的临时投影。

`estimator_info['numerical_solver'] == 'stable_tsqr'` 标记困难分支。开启 profile 时，`iv_stages` 记录准备、原吸收、局部控制修正、列检查/自由度与完整 IV 内核的分阶段时间；局部修正单列为 `control_refinement_seconds`，不重复计入其它阶段。修正元数据进一步区分筛查、QR、方向构造、投影与映回时间。未新增公共数值阈值或用户调参项。

## 验证及边界

定向测试见 `tests/numerics/test_iv_conditioned_solve.py`：独立观察空间参考核对完整协方差、残差、一阶段和过度识别检验；覆盖权重、单位变换、重复观测、fweight字面复制、双向聚类、真欠识别、多内生变量诊断，以及共享强FE加载和弱连接FE的显式投影参考。

`test_iv_refinement_boundaries.py` 覆盖精确冗余、吸收后零列与近共线控制并存，及列顺序、单位、角色优先级和报错语义。`test_iv_hdfe_inference_reference.py` 独立构造加权dummy投影、FE秩、自由度、CGM聚类交集与有限样本修正，核验aweight双向聚类、权重和变量单位变化、fweight字面复制。参考先对实际浮点输入构造高精度可逆控制对比基，避免参考本身因逐列投影相消失准；不借用待测结果的自由度。

10万困难样本的局部修正约98.65%耗时来自投影迭代。曾测试在已有8次MAP之后增加最多512/1024次共享CG；两次都未通过原FE证书，仍须执行LSMR，局部耗时从3.16秒增至3.87/4.45秒，因此撤销该候选，保留原认证算法。该对照用于拒绝无收益候选，不作为统计性能基准。

QR/SVD 提高求解稳定性，不会增加模型本身的信息，也不能恢复吸收阶段已丢失的信息。数值秩阈值仍与原始 N 有关；极端边界的错误分类不保证对任意重复观测不变。大样本准确性与性能须分别报告，不能将旧版失败耗时用作成功估计的加速基准。未运行外部软件对照时不宣称 Stata parity。
