# 线性 IV 统计修复与投影复用

## 统计契约

聚类2SLS的原over-ID直接在2SLS残差矩条件上计算二次型，缺少有效GMM更新。现在以相同残差估计的矩条件协方差S固定权重W，令D=Z′X，计算

```text
g_eff = g − D (D′WD)^+ D′Wg
J = g_eff′ W g_eff
```

这与在固定W下更新有效GMM残差等价；返回的主估计系数仍是请求的估计器。过度识别自由度仍为工具矩阵列数减主回归矩阵列数。iid Sargan使用未做回归自由度修正的残差方差；恰好识别仍返回无over-ID统计。

线性IV采用ivreg2-small的nested VCE口径。将有效吸收自由度记为`max(df_a, nested_present)`，模型VCE与RMSE共用该计数；当df_a为正时不另扣reghdfe的nested单位，当df_a为零且存在nested FE时保留一个截距。首阶段推断同步采用该口径；OLS的嵌套修正和R²扩展定义保持原有契约。

完整结果缓存ABI从3升至4，防止恢复旧统计值。投影列缓存未失效，因为FE投影方程未改变。没有新增公共设置。

## 执行改动

- 常规2SLS复用共享求解器的首阶段系数和投影设计，供推断及首阶段输出使用。
- 无权重时复用已计算的投影矩阵；尽早释放求解结果中其余数组。
- IV协方差使用已有的直接X/残差聚类累加或分块稳健累加，避免完整得分副本。
- 诊断控制变量残差化合并右端项，一次GELSY代替两次；数值敏感的标量回退仍保留。
- GMM2S复用第一步的首阶段系数；其他k-class路径不再构造未使用的首阶段完整拟合矩阵。

没有改变识别/秩拒绝阈值、容差、工具、控制、FE、聚类、权重或diagnostics=off的计算契约。

## 回归验证

正式回归见 `tests/numerics/test_iv_correctness_closeout.py`：独立矩阵定义覆盖
dense/block、iid/robust/cluster、无权重/aweight/fweight，以及全部 nested 的截距边界。
既有病态、近不识别、只读/strided输入、近完美拟合、KP/SW、Session、权重与预测测试继续保留。

本机开发原型、外部对照原件和性能实验不随此变更上传；内部回归通过不代表
所有估计器、权重及跨平台组合均取得外部软件认证。
