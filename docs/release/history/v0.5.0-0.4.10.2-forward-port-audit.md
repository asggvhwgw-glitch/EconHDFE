## Canonical v0.4.10.2 A/B closeout

The final same-host cross-version benchmark now uses the actual final v0.4 baseline, v0.4.10.2. Across the seven-model 120k OLS/IV/PPML/IV-PPML matrix, coefficient/SE/VCOV and applicable result metadata are exactly identical. Three alternating timing rounds show no systematic single-regression regression.

Profiling a 300k complex event-study exposed one v0.5-only setup cost: after structural pruning left only six active columns, the execution planner still paid for a full topology scan and then selected dense storage. A narrow small-mixed-design fast path now skips that scan only when the surviving dense payload is small, pass count is low, memory is safe, and the localized width is small; genuinely localized, repeated-pass, wider, or memory-pressured designs still enter the exact block planner. The clean five-run alternating-process median is 0.5593 s for v0.4.10.2 and 0.5706 s for v0.5.0 (1.020x), with exact parity in coefficients/SE/VCOV-related model results, DoF, FE canonicalization, iteration count, and omission metadata. This difference is treated as timing noise rather than a performance claim. Machine-readable evidence is `benchmarks/planner/post_architecture/v050_vs_v04102_same_host.json`.

## Result

The v0.5.0 release artifacts now inherit the complete v0.4.10.2 support/reporting layer while preserving the v0.5.0 architecture work. No estimator-algorithm delta was required from v0.4.10.2.
