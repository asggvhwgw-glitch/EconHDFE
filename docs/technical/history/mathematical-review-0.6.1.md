## 2. 多向固定效应精确秩

### 2.1 明确对象

令 \(D=[D_1,\ldots,D_G]\) 为有限样本的分类截距哑变量设计，每个分区每行恰有一个 1，且每一列对应实际出现的水平。定义的是 **这个具体 0–1 矩阵的特征零秩**，不是仅由非零模式确定的 generic structural rank。后者是最大横截匹配数，只给实际秩一个上界；SciPy `structural_rank` 文档也明确区分二者。[S1]

反例：完整 2×2 双向设计的四行对应 (0,0)、(0,1)、(1,0)、(1,1)。其非零模式有大小为 4 的匹配，但两块哑变量列和相等，实际秩是 3。不能用稀疏匹配的“结构满秩”直接替代本包的 exact DoF。

### 2.2 11 项证明链核查

| 文稿命题 | 核查理由与必要条件 |
|---|---|
| Characteristic-zero equivalence | 整数矩阵的秩由非零子式刻画；整数子式在 Q 与 R 是否为零一致。因此 rank_Q(D)=rank_R(D)。 |
| Duplicate-edge reduction | 完全重复的矩阵行不改变行空间。仅用于秩；不用于未经加权聚合的观测残差。 |
| Component additivity | 行列按不相交支持分块排列后形成直和，秩可加。 |
| Exact leaf elimination | 若列仅在一个活动行有非零元，该列给出独立枢轴；用它清除该行的其他非零元，秩等于 1 加删除该行/列后的秩。 |
| Deterministic multipartite upper bound | 每个非空分量中 G 个块的列和相同，给 G−1 个线性独立列关系，故 rank≤min(E,V−G+1)。 |
| Exact column reduction | 从非首块各删一个参考列；用完整首块之和和本块其余列重构被删列，故保留相同列空间。 |
| Proper-connectivity rank formula | 下段给出独立推导；条件是“超边仅差一个坐标”的邻接图连通，不是一般关联图连通。 |
| Finite-field lower bound | 模 p 非零子式在整数域也非零，因此 rank_Fp≤rank_Q。 |
| Exact modular certificate | 若模秩等于已证明的 Q 秩上界 U，则夹逼得到精确秩 U；“p 很大”本身不是充分理由。 |
| Exact arbitrary-G rank | 上述保秩步骤复合；不能认证时走真正整数/有理消元，最终求和正确。 |
| Two-way formula | 双向关联矩阵每个连通分量秩 V_c−1，相加得到 K1+K2−C。 |

**Proper connectivity 的直接证明。** 固定根超边，每条只改变一个坐标的步进，其行向量差恰为该分区的两个单位向量之差。沿路径只累加改变第 g 个坐标的步进，得到任何该分区水平相对根水平的对比。因此行空间包含 V−G 个独立的分区内部对比，再加根行得到 V−G+1 个独立向量，与上界相等。这个证明无需把其他超图论文中可能不同定义的 “proper connectivity” 定理直接套用。Parui 的论文作为背景文献，而不是未经核对即可调用的黑箱引理。[S2]

**这个条件是充分而非必要。** 四条三向超边 000、011、101、110 的一坐标邻接图不连通，但其 Q 秩仍为 4=6−3+1；同一矩阵在 F2 上秩为 3。因此它同时检验了“不能把充分条件当必要条件”及“坏素数必须回退”两条边界。

### 2.3 实现核查与测试

`hdfe/rank.py` 的去重、剥叶、分量分解、GF(2) 预算、确定上界及 native 精确回退与证明链一致。预算耗尽只会损失一个认证机会，不应降低最终返回的精确秩。新增故障注入强制两次模认证都未达到上界，仍要求 native 有理结果正确。SymPy DomainMatrix 的域和 exact rank 接口已对照官方文档，但可选 FLINT 不在本次安装环境中，未把它写成实测通过。[S3]

独立 `Fraction` 消元不导入本包的消元函数，核对全部 4,095 个非空 2×2×3 支持集，以及 G=1…6 每个 G 的 35 组随机多重超图，并分别验证重复观测、行重排和分区重排不变性。它们是精确小实例证据，不是对所有有限超图的穷尽验证。

实际修复：`assume_dense=True` 原先允许 `[0,2,2]`，单向快速公式可能把未出现的水平 1 也计入秩；还允许小数截断。现在统一检查有限、非负、整数、目标类型范围及无空洞。默认非稠密模式仍按实际标签编码。没有把 exact 改成默认，也没有把纯分类证明外推到连续斜率、多成员 FE 或 cluster 小样本修正。

## 3. 残差核：数学正确，但求解状态也必须正确

### 3.1 四项结论的证明

考虑 \(\min_\alpha \sum_i w_i(y_i-d_i^T\alpha)^2\)，其中 \(0<w_i<\infty\)。若某活动哑变量系数 \(\alpha_v\) 只出现在行 i，其一阶条件是 \(w_i r_i=0\)，故 \(r_i=0\)。更强的消元论证是：固定所有其他系数后，总能选择该系数使第 i 行残差为零，所以对其余系数的约简目标函数恰好等于删去第 i 行后的目标。这直接证明“零残差”及“其余优化不变”两个引理。

按剥叶序列归纳，得到核心定理：核心行上求解约简投影，已剥行插入零，得到全样本投影残差。多个 RHS 各列独立，论证不变。正交性推论需同时保留 \(y-r\in\mathrm{col}(D)\) 和核心残差的正规方程；不能只凭一个随意向量满足部分正规方程就称其是原始投影。

这与已知 singleton 消元一致。Correia 2015 明确讨论多向 FE 需要迭代删除 singleton，以及其推断层影响；因此不能把“任意 G 反复剥叶”仅因换成超图语言就视为已认证首创。[S4]

### 3.2 不可越过的条件

重复 FE 元组的 y、权重或 X 可以不同；**数值投影不能沿用秩算法的直接去重**。只改变严格正权重的大小不改变剥叶拓扑，但必须更新实际加权投影器。零权重行不再由一阶条件强制零残差，且投影只在正权重支持上有相应唯一性；当前安全策略是撤销核心复用，而不是把正权重证明强行用于零权重。

新增测试构造重复元组携带不同 y 和权重，比较 G=3、4、5、MAP/LSMR、权重更新后的核心输出与显式加权哑变量最小二乘；剥去的行必须逐位为零。数学精确约简不等于核心浮点求解自动精确。

### 3.3 本轮额外修复

原核心输出检查仅识别 criterion 含 `cg` 的分支，直接 CG 的实际 criterion 是 `hestenes`。于是廉价目标改变量达到阈值后，可能漏掉核心 FE 正交性复核。本次测试在 4 向例子观察到约 4×10^-9 的残差误差，修复检查分支后原有严格断言通过，未放宽容差。核复核/抛光耗尽时保留失败状态。

LSMR/LSQR 的停止码也必须遵循实际语义：0/1/2/4/5 是对应求解/精度停止，3/6 是条件数停止，7 是迭代上限。原 `istop != 7` 的判断已在 FE 恢复、通用吸收及 group-individual 包装层统一修正；恢复诊断额外保留原始停止码、原因、条件估计和正规方程残差。0…7 全部做了恢复包装层故障注入，另有通用吸收器的条件数失败回归。[S5]

这次没有重定义所有非核心 CG 路径的历史 Hestenes 收敛准则；该准则不是任意问题上的逐元素误差保证。文稿现在明确区分投影恒等式与数值收敛。

## 4. 分区细化与跨领域函数依赖

### 4.1 九项结论核查

若细分区 Q 的每个水平唯一映射到粗分区 P，则存在 0–1 聚合矩阵 A，使 \(D_P=D_QA\)。这是 dummy-space inclusion；双向细化给同一列空间。对同一个 W，两组 FE 列空间相同，其加权投影和 FWL 变换相同。删除被更细 FE 完全包含的因子块由相同恒等式保证。

对于细因子块的基约简，某个粗单元必须已有保留的粗列，且其中实际出现的所有细列均活动，才能利用“粗列等于对应细列之和”删除其中一列。缺少参考细列会破坏这个恒等式的适用性。`active` 掩码不能当作仅用于显示的元数据。

乘以相同对角矩阵 \(\mathrm{diag}(m)\) 后包含关系依然成立，包括 m 某些值为零；但保留的粗列也必须乘同一个 m。未乘 x 的截距 FE，一般不能因此吸收随 x 变化的 slope block。

细化传递性通过水平映射复合直接得到；交互项定理把对每个粗组件的已认证确定关系组合起来，得到细联合元组唯一确定粗联合元组。有限多个保列空间步骤的复合证明最终主定理。算法只做这些充分的安全约简，不保证发现所有高阶多块集体依赖。

这种从 FD 推导 one-hot 特征线性关系、降低维度并恢复参数的思路已有 Abo Khamis 等人的原始论文。其第 5 节包含模型重参数化和由 FD 导出的指标恒等式。本包证明是适用于自身参数化的直接论证，不应声称借用了数据库结论就自动证明全部 HDFE 推断。[S6]

### 4.2 四处必须修正文稿的外延

**依赖图可能有环。** 两个重命名的相同分区相互确定，形成 A→B→A。原“DAG”表述不正确；实现使用可达关系，允许这种情况，真正的 DAG 是合并互相确定的等价类后的商图。文稿和源码说明现在称细化预序/有向闭包图。注意代码边存 `(coarse,fine)`，传统 FD 箭头则是 `fine→coarse`，两种方向现已明确区分。

**列空间不变不保证任意具名系数不变。** 例如两列 x、2x，拟合值只确定 \(\beta_1+2\beta_2\)，删除一个冗余列后不能要求剩余具名数值与原最小范数坐标相同。正确承诺是拟合值、以及经明确参数映射对应的可估线性函数不变；比较单个系数还需同一可识别参数化和一致参照约束。仅移除冗余 FE 而保持 X 及其解选择规则不变时，系数不变可成立。

**删行不会破坏既有真 FD。** 一个 FD 的违反由一对同细值、不同粗值的行构成；取子集不可能创造这样一对。删 singleton 后再认证的意义是发现新依赖并刷新编码/活动列，不是此前真 FD 因删行而变假。增行、替换行或不一致的编码则须重新验证。

**元数据有信任边界。** 内部生成的组件包含关系可以是规格证明；任意外部伪造的 FEPartitionMeta 不是实数据证明。结构编译器的精确性建立在真实代码/组件关系上。

独立测试枚举 4 个细水平的所有非空活动掩码、2 个粗水平的所有非空活动掩码，分别使用纯 dummy 和含零/负值的共同乘子，共 90 个组合；直接用整数矩阵和 Fraction 秩核对约简前后列空间维数。另测不同乘子不可吸收、等价组件环、FE 规范化和删行 FD 保持。

## 5. 其他跨领域算法及数值尺度

**分块 QR / TSQR。** 每块对 `[sqrt(W)X, sqrt(W)y]` 做正交压缩，任意试探系数的加权平方目标值保持；共享列的剩余系统需全局求解，不能把含共享列的问题当独立块分别回归。局部秩不足时，必须回退到紧凑全局系统以保留全局最小范数选择。新测试覆盖有/无共享列、有/无秩亏、两种分块大小和零权重，对照全局 `lstsq`，并独立核对任意试探参数下目标值。TSQR 属于既有正交约简技术，不能单独登记为新算法。[S7]

**Schur/PCG。** 二向 FE 法是在连接分量内施加规范化后消元；实现复用的是求解方法，不证明多向额外零空间不存在。后估计层现在通过 `solve_coefficients` 获取用户原始项顺序和诊断，不再直接操作吸收器私有重排字段。可识别性仍由 exact rank/nullity 与规范化规则另行判定。

**尺度平衡不是任意问题的条件数治愈。** 新密集 OLS/WLS 求解使用列尺度平衡和分块 QR/SVD，并由同一组奇异方向给出 β、bread、rank。数学上，非零列单位变化 X*=XS 应满足 β*=S^-1β，V*=S^-1VS^-1。它修复单位变化导致的截断不一致；不能消除真正近共线问题。只剩 Gram 的流式路径使用平衡后的 Gram 逆，不能恢复形成 Gram 时已经丢失的信息。秩亏时应先确定可估列和参数化，不能要求任意最小范数坐标单位不变。

**线性 IV。** 本轮进一步复现原 2SLS 改变内生变量/工具变量单位后 β 和 SE 错误。现在在角色空间内平衡并还原 β、协方差、首阶段系数/拟合值和 GMM 元数据。24 组独立单位变换测试覆盖 2SLS、LIML、k-class、GMM2S × IID/robust/cluster × 大小尺度；保留估计方程和统计默认设置。LIML 的 outcome 尺度也另有守卫。

**PPML。** y 和 mu 同除 y_scale 时 model/IID Hessian 的逆改变尺度；最终应再除 y_scale。robust sandwich 的 bread/meat 缩放则抵消，不能给所有 VCE 统一套修正。两套 PPML 引擎及分块异质路径已修复，原独立 GLM/Hessian/sandwich 对照继续保留。

**退化推断。** 单聚类不是“方差为零的完美估计”。新代码阻止其生成有效 cluster 推断；t 自由度非正/非有限时不再静默切换正态并打星。这是统计对象有效性检查，不是数学秩定理的新推论。
