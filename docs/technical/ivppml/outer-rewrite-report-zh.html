1. 已实现的内容

新增 econhdfe/models/ppml_iv/outer.py 和 econhdfe/iv/step.py。前者负责矩方程、方向验证、步长和停止；后者负责可回退的加权 IV 线性步。irls.py 只增加显式分派，旧循环保留。estimator.py 在新路径上复用已认证的最终状态，不再追加未经验证的“只更新 β、不更新 η/μ”的最后一步。

每轮使用增量工作响应 (y−μ)/μ，而不是反复从水平值重新拼装全部求解状态。上一轮 residualized X/Z 可在新权重下继续残差化；变化的工作响应必须重新设置。每个线搜索试探只计算指数、工具变量矩与 FE 分组矩，不再次调用 FE 投影或 2SLS。

当前支持 dense 解释变量/工具变量和分类截距 FE。结构化 BlockDesign 路径明确拒绝新模式，不静默切回另一种算法。新模式默认仅启用 FE 零组清理，不把普通 PPML 的解释变量 separation 判据当成一般 IV 存在性判据。

2. 理论纠正：必须区分三件事

Poisson 似然不是一般 IV 矩方程的目标函数

设 η=o+Xβ+Dα、μ=exp(η)，用户权重为 W₀，Newton 权重为 W=W₀diag(μ)。加性 IV 条件使用工具变量矩，而不是普通 Poisson 的解释变量 score。因而正确的 IV 更新可以增加 Poisson deviance。[1]

一个解析反例：y=(3,1,2), x=(−1,0,1), z=(0,−1,1)，初始截距为 log 2、斜率为 0。IV Newton 方向为 Δα=0, Δβ=1/2，但负 Poisson 对数似然沿该方向的导数为 +1/2。其 IV 解为 β=log((7+√69)/10)。专项测试同时验证解析解、矩残差归零和似然上升，说明拒绝此类更新不是普遍正确的做法。

恰好识别：有明确的 Newton 方程

X̃ = M_W X,  Z̃ = M_W Z
G = Z̃′WZ̃,  C = Z̃′WX̃,  ν = Z̃′W₀(y−μ)
Δβ = (C′G⁻¹C)⁻¹ C′G⁻¹ν

恰好识别且 C 非奇异时：Δβ = C⁻¹ν
连同 FE 更新：Q′WA Δθ = Q′W₀(y−μ)，Q=[D,Z]。

这就是 F(θ)=Q′W₀[y−exp(o+Aθ)]=0 的 Newton 方程。新实现直接检验真实的线性化矩残差，不仅用一个经验性的 FE 容差代替它。

过度识别：保留原有估计方程，不偷偷更换估计量

Ψ(θ) = [ D′W₀(y−μ) ; C′G⁻¹ Z̃′W₀(y−μ) ] = 0。

此时不能要求所有原始样本矩都为零。本版保留上述 projected-IV 固定点方程；每次试探固定当前有效工具变量，下一轮重新构造后再验证收敛。它不等于固定权重 GMM，也不等于连续更新 GMM 的完整梯度。有效工具变量对参数的导数没有包含在方向中，所以不能把它称作 Ψ 的完整 Newton 方法，也不能宣称过度识别模式具有一般全局或二次收敛保证。存在多个根时，改变初始化和步长规则仍可能选择不同的根。

3. 能保证什么，不能保证什么

恰好识别时，固定正缩放 S，记 f=SF、φ=½‖f‖²。对计算方向 d，程序检查 e=f+J_f d，要求 ‖e‖≤γ‖f‖，默认 γ=0.25。于是：

φ′(0) = f′(e−f) ≤ −(1−γ)‖f‖² < 0。

这是可证明的下降方向条件。在可微性和精确算术下，足够短的 Armijo 步长存在。进一步的全局收敛需要适当水平集、识别后的非奇异性和 Jacobian 正则性等条件；超线性/二次局部速度还需要更强的 forcing 衰减条件。[2][3] 实现有有限的回退次数和浮点精度下限，因此不承诺无条件终止或任意精度二次收敛。

新模式返回成功时，同时通过当前标准化估计方程残差、相对 predictor/系数修正量和最终内层精度检查。方向证书失败时先提高内层精度，再尝试稳定 IV 求解；仍不满足即显式失败。试探均值溢出/下溢时拒绝该步，不靠截断 η 或强制均值下限改变问题。过度识别模式只保证当前步的冻结目标下降及返回点的重新认证，不把二者扩大为全局定理。

推断使用同一返回点的 β、η、μ、bread 和结构残差。它保持已有 robust/cluster 及频数权重约定，经过独立全 dummy sandwich 对照；这不是新的弱 IV 有效推断、多 incidental parameter 渐近理论或无偏性证明。

消融：速度来自哪里

在百万行、三维 FE、9 个工具变量的同一新外层内，将 tall-design 稳定线性求解替换为 guarded sufficient statistics，线性求解累计中位数由 2.595 秒降至 0.946 秒，快 2.74 倍；完整估计由 11.126 秒降至 9.472 秒，快 1.17 倍。这把线性核收益与初始化、收敛规则等外层变化分开。

新模式该场景的 FE 投影中位数约 5.495 秒；矩检查约 0.183 秒，步长搜索约 0.092 秒。剩余主要瓶颈不是 Python 的外层控制语句。本轮没有新增 Rust 扩展：大计算已由 BLAS/LAPACK、NumPy 和 Numba 执行。是否进一步用 Rust 融合归约/拷贝，应由后续剖析决定，而不是以语言替换代替算法优化。

复杂度和内存边界

每次 fast IV 线性步：O(N(L²+LK)+L³+LK²)
额外矩阵工作区：O(b(K+L)+L²+LK+K²)，另加 N 维残差输出。

K 为非 FE 解释变量数，L 为非 FE 工具变量数，b 为分块行数，默认 65,536。该界不包含已有设计矩阵、FE 工作区或最终推断存储，也不适用于回退到稳定 tall-design 求解的分支。Gram 条件数筛查与小型 SVD 是数值保护，不是任意精度的系数前向误差界。

6. 使用与交付内容

from econhdfe import IVPPMLConfig, ExecutionConfig, ivppmlhdfe

cfg = IVPPMLConfig(
    outer_solver="moment",       # 显式启用；默认仍是 legacy
    outer_linear_solver="auto",  # 分块充分统计量 + 数值回退
    singleton_mode="unified",    # 样本政策与外层算法分开选择
    engine="optimized",          # 两组基准使用同一个 FE 后端
    tolerance=1e-9,
    target_inner_tol=1e-10,
)
result = ivppmlhdfe(
    y=y, exog=C, endog=E, instruments=Z_excluded,
    absorb=[firm, year], config=cfg, vce="robust",
    execution_config=ExecutionConfig(threads=4),
)
print(result.diagnostics["outer"])

完整交付包含源码、可安装 wheel/sdist、相对主分支的 patch、36 项新测试、五组重复性能数据、35 次运行的 JSON/日志、同机复现脚本、理论说明和本报告。大型逐观测 .npz 输出已用于校验，但未装进交付包；可用同一固定种子脚本重建。validation/iv_outer/summary.json 给出逐项误差和性能判定，provenance.json 记录基线 CI artifact 与代码哈希。

默认兼容路径保持不变。正式启用新模式之前，应保留对目标数据的并行结果核对，特别是近分离、接近识别失效、多根和未覆盖的 FE/结构化设计。算法更可靠地拒绝错误收敛，不等于它能创造不存在的有限 IV 解。
